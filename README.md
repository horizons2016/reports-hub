# مستودع البحوث والتقارير · Reports Hub

رصد آلي لإصدارات **المركز الوطني للإحصاء والمعلومات** في سلطنة عُمان: كل إصدار جديد، وكل تعديل صامت على ملف منشور، وحداثة بيانات SDMX، في لوحة واحدة مع تنبيهات للفريق.

**اللوحة:** https://horizons2016.github.io/reports-hub/

## لماذا

يستبدل المركز أحياناً ملفات إصدارات منشورة بنسخ معدّلة دون أن يكتب رقم نسخة على الغلاف. من نزّل الملف يوم النشر قد يعمل بأرقام تغيّرت. هذا المستودع يرقّم النسخ (v1، v2…) ويُنبّه عند كل تعديل، ويؤرشف كل نسخة.

## للفريق: كيف تصلك التنبيهات

1. ادخل هذا المستودع بحسابك على GitHub.
2. اضغط **Watch** ← **Custom** ← فعّل **Issues** ← Apply.
3. كل تنبيه يُفتح كـ Issue ويصلك على بريدك. أو تابع [صفحة التنبيهات](../../issues) أو خلاصة RSS: `https://horizons2016.github.io/reports-hub/data/feed.xml`.

| التنبيه | معناه |
|---|---|
| إصدار جديد | أول ظهور للإصدار في قائمة المركز |
| تعديل | ملف جديد لإصدار قائم، ومحتواه مختلف عن السابق |
| تعديل على نفس الرابط | تغيّر المحتوى دون تغيّر الرابط (يُفحص خلال أول 15 يوماً) |
| ملف أُضيف | ظهر ملف جديد لإصدار قائم، غالباً Excel بعد PDF |
| SDMX: فترة جديدة | أُضيفت فترة زمنية إلى ملف من صفحة البيانات الوطنية الموجزة |

إعادة الرفع بنفس المحتوى تُسجَّل في اللوحة ولا تُرسل تنبيهاً.

## كيف يعمل

```
GitHub Actions (مرتين يومياً: 06:17 و14:17 بتوقيت مسقط)
  └─ collector/run.py
       ├─ يقرأ قائمة إصدارات المركز (واجهة البيانات التي يستخدمها موقع المركز)
       ├─ لكل ملف: وقت الرفع من اسمه + بصمة المحتوى SHA-256
       │    رابط جديد + بصمة مختلفة  → تعديل → Issue
       │    رابط جديد + بصمة مطابقة  → إعادة رفع (تسجيل فقط)
       ├─ يعيد فحص ملفات آخر 15 يوماً (يكشف الاستبدال على نفس الرابط)
       ├─ يقرأ 20 ملف SDMX من nsdp.ncsi.gov.om ويقيس حداثتها
       ├─ يحفظ data/*.json ويؤرشف النسخ الجديدة في Releases
       └─ ينشر اللوحة على GitHub Pages
```

| المجلد | المحتوى |
|---|---|
| `collector/` | الكود (Python) |
| `config/settings.json` | الإعدادات: فترة المراجعة، ملفات SDMX، عدد التنبيهات القصوى |
| `config/indicators.json` | ربط مؤشرات الرؤية بمصادرها (يُملأ بعد اعتماد المنهجيات) |
| `config/bulletin_tables.json` | جداول النشرة الشهرية وأفضل مصدر آلي لكل جدول |
| `data/` | البيانات التي يكتبها الرصد (لا تُعدَّل يدوياً) |
| `site/` | اللوحة |

## تشغيل يدوي

**Actions** ← **رصد إصدارات المركز (collect)** ← **Run workflow**. لا يحتاج أي تثبيت على جهازك.

## إضافة مؤشر

أضف عنصراً في `config/indicators.json`:

```json
{
  "id": "IND-01",
  "name_ar": "معدل الباحثين عن عمل",
  "priority": "سوق العمل والتشغيل",
  "methodology": "عدد الباحثين ÷ قوة العمل العمانية",
  "sources": [{"type": "nsdp", "ref": "LaborMarket", "label": "SDMX: سوق العمل"},
              {"type": "bulletin_table", "ref": "20", "label": "النشرة الشهرية، جدول 20"}],
  "needs": "تفصيل حسب المحافظة والفئة العمرية"
}
```

## حدود معروفة

- البصمة تقول إن الملف تغيّر، ولا تقول أي رقم تغيّر. مقارنة الجداول خلية بخلية مرحلة لاحقة.
- قبل بدء الرصد لا نعرف عدد مرات استبدال كل ملف؛ نعرف فقط أنه استُبدل مرة على الأقل.
- إذا غيّر المركز طريقة نشر قائمته، يظهر تحذير في أعلى اللوحة ويُعاد اكتشاف المصدر تلقائياً في التشغيل التالي.
